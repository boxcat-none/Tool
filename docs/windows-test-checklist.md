# Windows 實機測試清單（M1）

請在 Windows 10／11 實機上照順序操作，在每一項後面標記 ✅ 正常、❌ 有問題（並簡述看到什麼）、➖ 沒測。
有問題的項目請附截圖。不需要每一項都測，**粗體**是最重要的。

## 0. 安裝

安裝檔：GitHub → Actions → 「軟體版」→ 最新一次執行 → 下方 Artifacts → `PDF-Toolbox-Windows`
（裡面有 `.msi` 與 `-setup.exe`，擇一安裝即可）

- [ ] **安裝完成並能開啟**（安裝檔沒有程式碼簽章，會出現 SmartScreen：「其他資訊」→「仍要執行」）
- [ ] 開始功能表與桌面捷徑的名稱是「PDF Toolbox」，圖示正常

## 1. 閱讀與筆記（開啟程式預設就在這裡）

- [ ] **開啟一份真實的 PDF**（課本、講義），中文顯示正常
- [ ] 縮放（Ctrl＋滾輪、Ctrl+加號／減號）、翻頁、側邊欄縮圖與目錄
- [ ] 搜尋中文（Ctrl+F）
- [ ] **用滑鼠寫字**：鋼筆、螢光筆（字還看得到）、橡皮擦、復原（Ctrl+Z）、重做
- [ ] **如果有觸控筆或繪圖板**：寫字有沒有延遲、筆壓（輕重）有沒有讓粗細改變、手掌放在螢幕上會不會畫出線（勾「只用觸控筆」再試一次）
- [ ] **插入頁面**（橫線、方格、點陣、空白），在插入的頁面上寫字
- [ ] 側邊欄移動、刪除頁面，再按復原
- [ ] **關閉程式再開啟**：書櫃裡的筆記本、筆跡都還在
- [ ] **存成 .guganote**（Ctrl+S），刪掉書櫃裡的那本，再開啟 .guganote 檔，內容回來
- [ ] **匯出 PDF**，用 Edge 或 Acrobat 開啟，筆跡與插入的頁面都在
- [ ] 有密碼的 PDF：輸入密碼開啟、插頁、匯出
- [ ] 大檔案（100 頁以上）：開啟、翻頁、插頁的速度（大概幾秒）
- [ ] PDF 裡的網址連結：點了會用預設瀏覽器開啟

## 2. PDF 工具（上方切換到「PDF 工具」）

- [ ] 合併、分割、整理頁面、JPG/PNG 轉 PDF、PDF 轉 JPG/PNG：各試一次，存檔對話框正常
- [ ] **檔名有中文、存到中文資料夾**（例如「文件\報告.pdf」）
- [ ] Office 轉 PDF：
  - [ ] 沒裝 LibreOffice 時，顯示「需要先安裝 LibreOffice」
  - [ ] 裝好 LibreOffice 後按「重新偵測」，Word／Excel／PowerPoint 能轉成 PDF
  - [ ] 轉檔時不會跳出黑色命令列視窗

## 3. 其他

- [ ] Windows 深色模式下畫面正常
- [ ] 高解析度螢幕（顯示比例 150%、200%）下文字與筆跡清晰

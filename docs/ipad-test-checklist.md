# iPad 實機測試清單（W6）

網址：**https://boxcat-none.github.io/Tool/**（用 Safari 開啟）

每一項標記 ✅ 正常、❌ 有問題（簡述或截圖）、➖ 沒測。**粗體**是最重要的。

## 0. 加入主畫面

- [ ] **Safari 分享按鈕 →「加入主畫面」**，主畫面出現「PDF 工具箱」圖示（橘色文件）
- [ ] 從主畫面開啟：全螢幕（沒有 Safari 網址列）
- 注意：**主畫面的 App 和 Safari 分頁的資料是分開的**（iPadOS 的規定）。在 Safari 分頁建立的筆記本，
  主畫面 App 看不到；要搬過去請在 Safari 分頁「存成 .guganote」，再到主畫面 App 開啟。之後建議都用主畫面 App。

## 1. Apple Pencil 書寫

- [ ] **第一次用筆畫線時，出現「偵測到觸控筆，已開啟『只用觸控筆』」**
- [ ] **用筆寫字不會再出現藍色反白、放大鏡或選單**
- [ ] 線條跟手程度（和之前比較）：延遲感有沒有改善
- [ ] 筆壓：輕寫細、重寫粗
- [ ] **手掌放在螢幕上寫字，不會畫出多餘的線**
- [ ] 螢光筆（字還看得到）、橡皮擦、復原、重做
- [ ] 快速點幾下畫點，不會觸發頁面縮放

## 2. 手指操作（「只用觸控筆」開啟時）

- [ ] **一指上下捲動頁面**
- [ ] **兩指縮放**（放大、縮小），工具列不會跟著放大
- [ ] 兩指縮放後筆跡位置正確、字清楚
- [ ] 關掉「只用觸控筆」：手指可以畫線；畫到一半放下第二根手指，那一筆會取消並改成縮放

## 3. 頁面與檔案

- [ ] 從「檔案」App 開啟 PDF（iCloud 雲碟、下載項目）
- [ ] 插入橫線／方格頁並書寫
- [ ] 側邊欄縮圖顯示筆跡、移動、刪除頁面
- [ ] **大檔案（100 頁以上）**：捲動、縮放、翻到後面再回來，不會變慢到不能用、不會自動重新載入
- [ ] 存成 .guganote、匯出 PDF：檔案存到哪裡（通常在「檔案」App 的「下載項目」）
- [ ] 從「檔案」App 開啟 .guganote

## 3-1. 圖片（W12）

- [ ] 工具列「插入圖片」→ 從「照片」選一張直拍的照片：方向正確（不會躺著）
- [ ] 插入後自動切到「選取」工具：**手指或筆按住圖片拖曳**可以移動；按住四個角拖曳可以縮放
- [ ] 「只用觸控筆」開啟時：手指按在圖片上是拖曳圖片，按在空白處是捲動頁面
- [ ] 點「刪除」刪掉圖片，按復原可以救回
- [ ] 在圖片上用筆寫字，字在圖片上面
- [ ] 匯出 PDF：圖片和筆跡都在
- [ ] 選取圖片後按「旋轉」：每次順時針轉 90 度

## 3-2. 套索選取（W13）

- [ ] 「選取」工具，**用筆在空白處畫一圈**：圈到的筆跡（和圖片）出現虛線框
- [ ] 筆或手指按住虛線框拖曳：一起移動；按一次復原就回到原位
- [ ] 虛線框上方的顏色：把選到的字改成別的顏色
- [ ] 「刪除」或復原
- [ ] 「只用觸控筆」開啟時：手指在空白處仍然是捲動，不會畫出套索

## 3-2-1. 心智圖（上方切到「心智圖」）

- [ ] 新增心智圖；按「＋子元件」「＋同層」，用螢幕鍵盤或中文輸入法輸入文字
- [ ] 手指點兩下元件可以編輯；用 Apple Pencil 點也可以
- [ ] 手指拖曳元件到另一個元件上，變成它的子元件；拖到空白處會停在那裡（只有它動，子元件和其他元件不動），「自動排列」恢復；拖曳空白處移動畫面；兩指縮放
- [ ] 長按元件、線條、空白處，各自跳出操作選單；改形狀、線型、虛線、顏色
- [ ] 長按空白處「新增元件」：出現在按的位置，沒有連線；選取一個元件，用手指從旁邊的黃色圓點拉到這個元件，多一條線（原本的線還在）；也可以拉到中心元件；長按線條「刪除線條」，只刪那條線
- [ ] 拖亂幾個元件、加兩個獨立元件，選取它們按「自動排列」：有連線的回到原位，獨立元件排成整齊的一列
- [ ] 只有一兩個字的元件也不會太小，手指容易點到
- [ ] 用 Apple Pencil 在空白處拖曳拉出選取框，選到的元件一起拖動
- [ ] 切換結構（心智圖、邏輯圖、組織圖、樹狀圖）與樣式（A～E）
- [ ] 關掉 App 再開，心智圖還在
- [ ] 「匯出 → PNG 圖片」可以存到照片或檔案
- [ ] iPhone：工具列可以左右滑，所有按鈕都按得到

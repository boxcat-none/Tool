# iPad 實機測試清單（W6）

網址：**https://boxcat-none.github.io/Tool/**（用 Safari 開啟）

每一項標記 ✅ 正常、❌ 有問題（簡述或截圖）、➖ 沒測。**粗體**是最重要的。

## 0. 加入主畫面

- [ ] **Safari 分享按鈕 →「加入主畫面」**，主畫面出現「PDF 工具箱」圖示（橘色文件）
- [ ] 從主畫面開啟：全螢幕（沒有 Safari 網址列）
- 注意：**主畫面的 App 和 Safari 分頁的資料是分開的**（iPadOS 的規定）。在 Safari 分頁建立的筆記本，
  主畫面 App 看不到；要搬過去請在 Safari 分頁「存成 .guganote」，再到主畫面 App 開啟。之後建議都用主畫面 App。

## 1. Apple Pencil 書寫

- [ ] **第一次用筆畫線時，出現「偵測到觸控筆，已開啟『只用觸控筆』」**
- [ ] **用筆寫字不會再出現藍色反白、放大鏡或選單**
- [ ] 線條跟手程度（和之前比較）：延遲感有沒有改善
- [ ] 筆壓：輕寫細、重寫粗
- [ ] **手掌放在螢幕上寫字，不會畫出多餘的線**
- [ ] 螢光筆（字還看得到）、橡皮擦、復原、重做
- [ ] 快速點幾下畫點，不會觸發頁面縮放

## 2. 手指操作（「只用觸控筆」開啟時）

- [ ] **一指上下捲動頁面**
- [ ] **兩指縮放**（放大、縮小），工具列不會跟著放大
- [ ] 兩指縮放後筆跡位置正確、字清楚
- [ ] 關掉「只用觸控筆」：手指可以畫線；畫到一半放下第二根手指，那一筆會取消並改成縮放

## 3. 頁面與檔案

- [ ] 從「檔案」App 開啟 PDF（iCloud 雲碟、下載項目）
- [ ] 插入橫線／方格頁並書寫
- [ ] 側邊欄縮圖顯示筆跡、移動、刪除頁面
- [ ] **大檔案（100 頁以上）**：捲動、縮放、翻到後面再回來，不會變慢到不能用、不會自動重新載入
- [ ] 存成 .guganote、匯出 PDF：檔案存到哪裡（通常在「檔案」App 的「下載項目」）
- [ ] 從「檔案」App 開啟 .guganote

## 4. 離線

- [ ] 開過一次之後，**開啟飛航模式**，從主畫面開啟：書櫃、筆記本、書寫、插頁都正常

## 5. 其他

- [ ] 直向、橫向旋轉後畫面正常
- [ ] 深色模式

# 心智圖（獨立開發）

使用者要求先獨立開發，完成後再和「閱讀與筆記」合併。所以心智圖有自己的 package、自己的儲存，**不碰筆記本的程式**；之後合併時再決定放進筆記本的方式（見最後一節）。

## 用詞與起始畫面（使用者 2026-11-18 指定）

- 圖上的方塊在介面上一律叫「**元件**」（新增子元件、同層元件、N 個元件…），不叫「主題」。程式裡的資料型別仍叫 node。
- 新增心智圖時只有一個**圓角方塊**，文字是「**主題**」（中心元件；`style.shape = "rounded"`）。新加的元件預設文字是「新元件」。
- 元件有最小大小：有框的形狀至少 120×44（中心元件寬 140），底線形狀至少寬 80。字很少時元件也不會太小。（使用者 2026-11-18 指定）

## 連接線與獨立元件（使用者 2026-11-18 指定）

- **右鍵點元件**新增的元件（子元件、同層）會自動連線；**右鍵點背景**「新增元件」只產生元件（**獨立元件**，不連線），放在按右鍵的位置。
- 線可以自己拉：選取一個元件，旁邊出現圓點，從圓點拉到另一個元件放開 = 多一條線（**手拉的線**）。**不會改變任何元件的上層、不會斷掉原本的線、位置不動**；可以連到中心元件，一個元件可以有很多條線。拉線時指到可以連的元件會亮框，不能連的（自己、兩個之間已經有線）是紅框，放開不做任何事。（使用者 2026-11-18 指定：拉線不能斷開原本的連線、要能連到中心元件）
- 圓點的位置：沒有上層的元件（中心、獨立元件）左右兩邊都有；有上層的只放在對面那一邊，不會蓋住連進來的線；組織圖放在下面；收合的元件放在「+3」標記外面。
- 手拉的線一樣可以點選、框選、改線型、粗細、虛線、顏色；選線按 Delete 或線條選單「刪除線條」只刪那條線。
- 刪掉「上層 → 子元件」的線（線條選單、Delete、元件選單「拆掉連到上層的線」）：子元件和它底下的元件變成獨立元件，留在原地。
- 「上層 → 子元件」的線還是一棵樹（自動排版、收合、大綱匯出照舊）；手拉的線不影響排版，大綱匯出也不包含。收合後看不到的元件，連到它的手拉線也不畫。
- 線條的點擊範圍在元件下面：線經過元件時，按元件會選到元件。

### 資料模型

和筆記本一樣用 Yjs，之後才能多裝置同步：

```
meta   { schema, id, title, root, structure, theme, createdAt }
nodes  nodeId → { parent, order, text, collapsed?, color?, pos?, style?, at? }
links  linkId → { from, to, line?, width?, dash?, color? }   手拉的線
```

- 獨立元件 = `parent: null` 的元件（中心元件以外），位置是 `at = [x, y]`（左上角，排版座標，各種結構共用）。連上線後刪掉 `at`。

- `style` = 單一元件的外觀設定 `{ shape?, line?, width?, dash? }`，沒設定的沿用樣式主題。
- `pos` = 自由拖動後的位移 `{ 結構: [dx, dy] }`，相對自動排版的位置；會傳給子元件，所以只拖上層時，沒選到的子元件反方向補回來（畫面上不動）。中心元件也可以有位移。每種結構各自記錄，換結構不會亂掉；換到別的父節點時清掉。

- 獨立元件的子元件照常記父節點；別台裝置刪掉獨立元件時同時加的子元件，接到中心元件（不遺失）。
- 每個節點只記父節點與兄弟間的順序（fractional indexing）。兩台裝置同時移動同一個節點，只有最後一次生效，不會出現兩份。
- 兩台裝置同時把 A 拖到 B 底下、把 B 拖到 A 底下會形成迴圈；**讀取時**遇到迴圈或父節點已刪除，就把節點接到中心元件（所有裝置結果一致），資料不遺失。單元測試有這兩種情況。
- 結構、元件存在文件裡（換裝置開啟時外觀一樣）。

### 排版

`layoutForest(main, floating, measure, structure)` 先用 `layoutTree` 排中心元件的樹，再把每個獨立元件的樹排在它的 `at`（心智圖結構時往右展開，其他結構照原本方向），深度從 1 算，外觀和一般元件一樣。`layoutTree(tree, measure, structure)` 和畫面無關：節點大小由呼叫端量好傳入（網頁用 canvas `measureText`），所以可以在 Node 裡單元測試「不重疊」「左右平衡」。

- 心智圖：第一層分支依子樹高度分到右邊和左邊；左邊由下往上排（順時針閱讀）。
- 拖曳放下：放在節點中間 = 變成子元件；靠上（組織圖是靠左）四分之一 = 插在前面，靠下 = 插在後面。
- **自由拖動**：放在空白處（或按住 Shift／Alt）= 停在放開的位置；**只有拖的元件和其他選取的元件會動，子元件和其他元件不動**（使用者 2026-11-18 指定）；中心元件也可以拖；放到自己的子元件上 = 不做任何事。「回到自動排版的位置」也只動選取的元件。
- **排列**（使用者 2026-11-18 指定：選到的元件要全部排好，不能只排一個）：
  - 選了多個元件時，工具列「自動排列」和元件選單「排列選取的 N 個元件」只排選到的：有連線的回到自動排版的位置（沒選到的子元件留在原地），獨立元件（連同底下的元件）依原本上下順序排成一列、左邊對齊，放在它們原本範圍的左上角。
  - 沒有選或只選一個時，「自動排列」排整張圖：所有元件回到自動排版的位置，所有獨立元件排成一列放在中心元件那棵樹的右邊。
  - 一次復原。「自動排列」清掉目前結構的所有位移。
- 連接線的方向依實際位置決定：把元件拖到中心元件的另一側，線會從另一側出來。
- 文字自動換行：一行最寬約 220px（14px 字；字越大越寬），中日韓文字每個字都可以斷、英文以單字為單位。量測與繪製共用 `wrapLines()`，元件大小和畫出來的行數一致。
- 編輯文字：透明的輸入框直接放在元件的文字位置上；打字時用正在打的文字重新排版，元件即時變大、換行，連接線跟著調整。
- 拖曳中用 `moveNodes()` 產生暫時的排版直接畫出來，所以連接線即時跟著動（沒有半透明的預覽影子）。

### 操作（使用者 2026-11-18 指定）

| 操作 | 滑鼠 | 觸控（iPad） |
|---|---|---|
| 移動整張圖 | **右鍵**按住拖曳（任何地方）；滾輪 | 一指拖背景、兩指 |
| 框選元件與線條 | **左鍵**按住背景拖曳（Shift 加選）；Ctrl+A 全選 | 觸控筆拖背景 |
| 操作選單 | **右鍵點一下**：元件、線條、背景各有不同選項 | 長按 |
| 選取線條 | 點線條（Shift 加選） | 點線條 |
| 一起移動 | 多選後拖其中一個（一律自由放置） | 同左 |
| 拉線連接 | 從選取元件旁的圓點拖到另一個元件 | 同左（手指或觸控筆） |
| 刪線 | 選線條按 Delete；線條選單「刪除線條」 | 長按線條 →「刪除線條」 |

- 元件選單：新增子元件／同層、編輯文字、收合、顏色、形狀（圓角、膠囊、方框、卡片、橢圓、底線）、連到父元件的線（線型、粗細、虛線）、回到自動排版的位置、刪除。多選時一次改全部。
- 線條選單：線型（曲線、直角、直線）、粗細、虛線、顏色、選取線條兩端的元件、刪除線條。線條的設定存在子元件上（`style.line/width/dash`）。
- 背景選單：新增元件（獨立元件，不連線）、全選、整張圖置中、實際大小、自動排列、結構、樣式、匯出 PNG。

## 匯出與匯入（使用者 2026-11-25 指定：照業界做法）

2026-11-25 查過 XMind、MindNode：業界用 PNG／SVG／PDF 給人看，FreeMind（.mm）和 OPML 在不同軟體之間搬資料，Markdown 給文件與 AI，自己的格式做完整備份；匯入支援的格式比匯出多。

| 格式 | 匯出 | 開啟（清單頁「開啟檔案」） | 保留什麼 |
|---|---|---|---|
| `.gugamap` | ✅ | ✅（同一張圖會合併） | 全部（Yjs 文件） |
| FreeMind `.mm` | ✅ | ✅ | 文字、層級、收合、分支顏色、手拉的線（`arrowlink`）、獨立元件（Freeplane 的 `FreeNode` 標記）；讀得懂 `richcontent` 的 HTML 文字 |
| OPML `.opml` | ✅ | ✅ | 文字、層級；獨立元件是另一個最上層 outline（`gugaFloating="true"`）。別的軟體存的 OPML 有很多個最上層時，以標題當中心元件 |
| Markdown `.md` | ✅ | ✅ | 文字、層級。`#` = 中心元件，`##`、`###`… 與清單縮排往下；之後的 `#` = 獨立元件；行內標記（粗體、連結…）去掉，程式碼區塊略過 |
| 純文字 `.txt` | — | ✅ | 每行一個元件，縮排表示層級 |
| PNG | ✅ | — | 外觀（最多 2 倍解析度） |
| SVG | ✅ | — | 外觀（向量） |
| PDF | ✅ | — | 外觀。一頁放整張圖，頁面大小跟著圖，內容是 3 倍解析度的圖片（不用另外嵌入中文字型） |

- 圖片（PNG、SVG、PDF）匯出前有選項視窗：整張圖／只匯出選取的元件（只畫兩端都選到的線）、透明背景。
- 匯入的獨立元件先排在右邊一列，打開後按「自動排列」整理。
- XML 用自己寫的小解析器（`parseXml`），套件測試在 Node 裡跑、不依賴瀏覽器的 DOMParser。

- 選單裡的選項（形狀、線型、顏色…）按了不會關閉，可以接著調整；一般動作按了會關閉。

### 樣式

| 代號 | 名稱 | 特徵 |
|---|---|---|
| `rainbow` | A 彩虹曲線 | 第一層分支各一色，線越往外越細 |
| `minimal` | B 極簡線條 | 灰色細線，文字在底線上 |

## AI 產生架構圖／流程圖（使用者 2026-11-25 指定）

使用者要接自己訓練的語言模型，把文字、文件、圖片轉成架構圖或流程圖。使用者選擇：模型跑在本機伺服器（OpenAI 相容 API）、兩種圖都要、文件要 HTML／PowerPoint／PDF／Word／文字／筆記本；模型看不看得懂圖片不確定。

| 部分 | 位置 |
|---|---|
| 提示詞、解析回答（JSON／Markdown／Mermaid）、流程圖排版、Word／PowerPoint XML 轉 Markdown、建立圖 | `packages/mindmap/src/ai.ts` |
| 連模型（`/chat/completions`、`/models`）、設定（存在這台裝置） | `apps/web/src/mindmap/ai/client.ts` |
| 檔案轉文字：PDF（pdf.js）、docx／pptx／guganote（解壓縮）、HTML（標題、清單）、圖片（縮到 1600 px） | `apps/web/src/mindmap/ai/extract.ts` |
| 對話框（清單頁「AI 產生…」） | `apps/web/src/mindmap/ai/AiDialog.tsx` |

- **連線**：OpenAI 相容 API，Ollama（預設 `http://localhost:11434/v1`）、LM Studio、vLLM、llama.cpp server 都可以；只填 `http://主機:埠` 會自動補 `/v1`。先要求 `response_format: json_object`，伺服器不支援（400／422…）時改一般模式再送一次。瀏覽器直接連，所以伺服器要允許這個網頁的來源（Ollama：`OLLAMA_ORIGINS`；LM Studio：開啟 CORS），連不上時錯誤訊息會寫出要設定的值。
- **提示詞**：要求只回答 JSON。架構圖 `{title, root:{text, children}}`；流程圖 `{title, nodes:[{id, text, type}], edges:[{from, to, label}]}`，type = start／end／process／decision／io。回答不照規矩時：架構圖接受 Markdown 大綱，流程圖接受 Mermaid（`flowchart TD`），也會略過 `<think>…</think>`。
- **流程圖**：存成同一種文件，`meta.kind = "flow"`、結構用組織圖；第一個「開始」是中心元件，其他是獨立元件，用手拉的線（有箭頭、線上文字）連。形狀：開始／結束 = 膠囊、步驟 = 方框、判斷 = 菱形、輸入輸出 = 平行四邊形。可以往回連（迴圈），往上的線從右邊繞回去。
- **流程圖排版**（`layoutFlow`）：簡化的 Sugiyama：去掉迴圈的線 → 每個元件的層 = 上一步的層 + 1 → 同層依鄰居位置來回排序減少交叉 → 盡量放在上一步正下方、同層不重疊。AI 產生的圖打開時先量元件大小再排（`layoutPending`，不算在復原裡），排好後置中；之後「自動排列」也是這個排版。
- **文件**：有結構的轉成 Markdown（Word 標題樣式 → #、清單 → -；PowerPoint 每張投影片標題 → ##；HTML h1～h6、ul／ol），模型比較容易整理。很長的內容只送前 N 字（預設 16000，可調）。`.ppt`／`.doc` 舊格式請另存新版。筆記本取裡面 PDF 的文字。
- **圖片**：設定勾「模型看得懂圖片」時以 `image_url`（data URL）送給模型；沒勾時說明要多模態模型。
- **不用 AI**：照標題、清單與段落轉成架構圖（段落太長截短），不送任何資料出去。

## 和筆記合併時要決定的事

- 心智圖放在筆記本的哪裡：① 筆記本裡的一種頁面（整頁是心智圖）② 插在頁面上的物件（像圖片一樣可以移動、縮放）③ 維持獨立，但書櫃一起列出。
- 書櫃要不要和筆記本共用清單（目前心智圖有自己的清單，存在 `guganote-mindmaps` 資料庫）。
- 裝置同步：模型已經是 Yjs，接上 `SyncSession` 即可；同步單位要一起決定（W10 書櫃層級同步）。
- 手寫：要不要讓節點裡可以手寫（Apple Pencil）。

# 心智圖（獨立開發）

使用者要求先獨立開發，完成後再和「閱讀與筆記」合併。所以心智圖有自己的 package、自己的儲存，**不碰筆記本的程式**；之後合併時再決定放進筆記本的方式（見最後一節）。

## 參考：其他工具怎麼做

2026-11-17 查過 XMind、MindNode、Miro、MindMeister、EdrawMind、Goodnotes，整理出這些共同功能：

| 類別 | 常見做法 | 第一版 |
|---|---|---|
| 結構 | 心智圖（左右放射）、邏輯圖（向右）、組織圖（向下）、樹狀圖（大綱縮排）、括號圖、魚骨圖、時間軸、矩陣；XMind 可以不同分支用不同結構 | ✅ 前四種；其餘見 backlog #24 |
| 節點形狀 | 底線、圓角、長方形、膠囊、雲朵、六角形、橢圓 | ✅ 依主題決定（膠囊、圓角、長方形、底線、橢圓、便利貼、卡片、斜標籤） |
| 分支 | 曲線／直角，粗細可調；彩虹（第一層分支各一色）、越往外越細 | ✅ 曲線、直角；彩虹與漸細在 A 主題 |

### 資料模型

和筆記本一樣用 Yjs，之後才能多裝置同步：

```
meta   { schema, id, title, root, structure, theme, createdAt }
nodes  nodeId → { parent, order, text, collapsed?, color? }
```

- 每個節點只記父節點與兄弟間的順序（fractional indexing）。兩台裝置同時移動同一個節點，只有最後一次生效，不會出現兩份。
- 兩台裝置同時把 A 拖到 B 底下、把 B 拖到 A 底下會形成迴圈；**讀取時**遇到迴圈或父節點已刪除，就把節點接到中心主題（所有裝置結果一致），資料不遺失。單元測試有這兩種情況。
- 結構、主題存在文件裡（換裝置開啟時外觀一樣）。

### 排版

`layoutTree(tree, measure, structure)` 和畫面無關：節點大小由呼叫端量好傳入（網頁用 canvas `measureText`），所以可以在 Node 裡單元測試「不重疊」「左右平衡」。

- 心智圖：第一層分支依子樹高度分到右邊和左邊；左邊由下往上排（順時針閱讀）。
- 拖曳放下：放在節點中間 = 變成子主題；靠上（組織圖是靠左）四分之一 = 插在前面，靠下 = 插在後面。不能放到自己的子孫上。

### 樣式

| 代號 | 名稱 | 特徵 |
|---|---|---|
| `rainbow` | A 彩虹曲線 | 第一層分支各一色，線越往外越細 |
| `minimal` | B 極簡線條 | 灰色細線，文字在底線上 |
| `boxed` | C 方框直角 | 方框＋直角線 |
| `sketch` | D 手繪便利貼 | 便利貼顏色、稍微歪斜、線有手繪抖動（依節點代號固定，重畫不會閃） |
| `node` | E 節點卡片（**預設**） | 使用者提供的截圖風格：深色畫布、圓角深色卡片、左右黃色連接點、細的 S 形曲線從連接點拉出；中心主題是黃底斜標籤 |

「分支顏色」：在 A、D 主題改分支的顏色；在 E 主題改連接點與線的顏色；子主題跟著用。

## 和筆記合併時要決定的事

- 心智圖放在筆記本的哪裡：① 筆記本裡的一種頁面（整頁是心智圖）② 插在頁面上的物件（像圖片一樣可以移動、縮放）③ 維持獨立，但書櫃一起列出。
- 書櫃要不要和筆記本共用清單（目前心智圖有自己的清單，存在 `guganote-mindmaps` 資料庫）。
- 裝置同步：模型已經是 Yjs，接上 `SyncSession` 即可；同步單位要一起決定（W10 書櫃層級同步）。
- 手寫：要不要讓節點裡可以手寫（Apple Pencil）。

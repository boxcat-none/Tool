# 心智圖（獨立開發）

使用者要求先獨立開發，完成後再和「閱讀與筆記」合併。所以心智圖有自己的 package、自己的儲存，**不碰筆記本的程式**；之後合併時再決定放進筆記本的方式（見最後一節）。

## 用詞與起始畫面（使用者 2026-11-18 指定）

- 圖上的方塊在介面上一律叫「**元件**」（新增子元件、同層元件、N 個元件…），不叫「主題」。程式裡的資料型別仍叫 node。
- 新增心智圖時只有一個**圓角方塊**，文字是「**主題**」（中心元件；`style.shape = "rounded"`）。新加的元件預設文字是「新元件」。

### 資料模型

和筆記本一樣用 Yjs，之後才能多裝置同步：

```
meta   { schema, id, title, root, structure, theme, createdAt }
nodes  nodeId → { parent, order, text, collapsed?, color?, pos?, style? }
```

- `style` = 單一元件的外觀設定 `{ shape?, line?, width?, dash? }`，沒設定的沿用樣式主題。
- `pos` = 自由拖動後的位移 `{ 結構: [dx, dy] }`，相對自動排版的位置；子元件跟著移動。每種結構各自記錄，換結構不會亂掉；換到別的父節點時清掉。

- 每個節點只記父節點與兄弟間的順序（fractional indexing）。兩台裝置同時移動同一個節點，只有最後一次生效，不會出現兩份。
- 兩台裝置同時把 A 拖到 B 底下、把 B 拖到 A 底下會形成迴圈；**讀取時**遇到迴圈或父節點已刪除，就把節點接到中心元件（所有裝置結果一致），資料不遺失。單元測試有這兩種情況。
- 結構、元件存在文件裡（換裝置開啟時外觀一樣）。

### 排版

`layoutTree(tree, measure, structure)` 和畫面無關：節點大小由呼叫端量好傳入（網頁用 canvas `measureText`），所以可以在 Node 裡單元測試「不重疊」「左右平衡」。

- 心智圖：第一層分支依子樹高度分到右邊和左邊；左邊由下往上排（順時針閱讀）。
- 拖曳放下：放在節點中間 = 變成子元件；靠上（組織圖是靠左）四分之一 = 插在前面，靠下 = 插在後面。
- **自由拖動**：放在空白處（或按住 Shift／Alt）= 停在放開的位置，子元件一起移動；放到自己的子元件上 = 不做任何事。「自動排列」清掉目前結構的所有位移。
- 連接線的方向依實際位置決定：把元件拖到中心元件的另一側，線會從另一側出來。
- 文字自動換行：一行最寬約 220px（14px 字；字越大越寬），中日韓文字每個字都可以斷、英文以單字為單位。量測與繪製共用 `wrapLines()`，元件大小和畫出來的行數一致。
- 編輯文字：透明的輸入框直接放在元件的文字位置上；打字時用正在打的文字重新排版，元件即時變大、換行，連接線跟著調整。
- 拖曳中用 `moveNodes()` 產生暫時的排版直接畫出來，所以連接線即時跟著動（沒有半透明的預覽影子）。

### 操作（使用者 2026-11-18 指定）

| 操作 | 滑鼠 | 觸控（iPad） |
|---|---|---|
| 移動整張圖 | **右鍵**按住拖曳（任何地方）；滾輪 | 一指拖背景、兩指 |
| 框選元件與線條 | **左鍵**按住背景拖曳（Shift 加選）；Ctrl+A 全選 | 觸控筆拖背景 |
| 操作選單 | **右鍵點一下**：元件、線條、背景各有不同選項 | 長按 |
| 選取線條 | 點線條（Shift 加選） | 點線條 |
| 一起移動 | 多選後拖其中一個（一律自由放置） | 同左 |

- 元件選單：新增子元件／同層、編輯文字、收合、顏色、形狀（圓角、膠囊、方框、卡片、橢圓、底線）、連到父元件的線（線型、粗細、虛線）、回到自動排版的位置、刪除。多選時一次改全部。
- 線條選單：線型（曲線、直角、直線）、粗細、虛線、顏色、選取線條兩端的元件。線條的設定存在子元件上（`style.line/width/dash`）。
- 背景選單：新增元件、全選、整張圖置中、實際大小、自動排列、結構、樣式、匯出 PNG。
- 選單裡的選項（形狀、線型、顏色…）按了不會關閉，可以接著調整；一般動作按了會關閉。

### 樣式

| 代號 | 名稱 | 特徵 |
|---|---|---|
| `rainbow` | A 彩虹曲線 | 第一層分支各一色，線越往外越細 |
| `minimal` | B 極簡線條 | 灰色細線，文字在底線上 |
| `boxed` | C 方框直角 | 方框＋直角線 |
| `sketch` | D 手繪便利貼 | 便利貼顏色、稍微歪斜、線有手繪抖動（依節點代號固定，重畫不會閃） |
| `node` | E 節點卡片（**預設**） | 使用者提供的截圖風格：深色畫布、圓角深色卡片、左右黃色連接點、細的 S 形曲線從連接點拉出；中心元件是黃底斜標籤 |

「分支顏色」：在 A、D 元件改分支的顏色；在 E 元件改連接點與線的顏色；子元件跟著用。

## 和筆記合併時要決定的事

- 心智圖放在筆記本的哪裡：① 筆記本裡的一種頁面（整頁是心智圖）② 插在頁面上的物件（像圖片一樣可以移動、縮放）③ 維持獨立，但書櫃一起列出。
- 書櫃要不要和筆記本共用清單（目前心智圖有自己的清單，存在 `guganote-mindmaps` 資料庫）。
- 裝置同步：模型已經是 Yjs，接上 `SyncSession` 即可；同步單位要一起決定（W10 書櫃層級同步）。
- 手寫：要不要讓節點裡可以手寫（Apple Pencil）。
